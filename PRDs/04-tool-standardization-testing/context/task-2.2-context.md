### Best Practice Example 1: LangChain DynamicStructuredTool Pattern

**Source**: https://github.com/sloppylopez/lang-chain-poc/blob/main/src/tools/code-validation.tool.ts
**Stars**: N/A | **Language**: TypeScript

```typescript
import { z } from "zod"
import { DynamicStructuredTool } from "@langchain/core/tools"

const validateJavaScriptCodeSchema = z.object({
	code: z.string().describe("The JavaScript code to validate."),
})

const validateJavaScriptCodeTool = new DynamicStructuredTool({
	name: "validateJavaScriptCodeTool",
	description:
		"Validates JavaScript code using ESLint to ensure it is syntactically correct and adheres to coding standards.",
	schema: validateJavaScriptCodeSchema,
	func: validateJavaScriptCode,
})
```

**Key Takeaways:**

- DynamicStructuredTool requires: name, description, schema (z.object), func
- Schema must be Zod object with descriptive fields using .describe()
- Function receives validated parameters as typed object
- Tool returns string result for LangChain integration
- Import pattern: `import { DynamicStructuredTool } from '@langchain/core/tools';`
