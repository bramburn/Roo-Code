# Markdown Templates for Curriculum Documentation

## Curriculum Root README.md Template

Use this template as a starting point for the main curriculum documentation:

```markdown
# {Language Pair} - Michel Thomas Method Curriculum

## Overview
This curriculum teaches {target language} to {source language} speakers using the proven Michel Thomas Method approach. Students will develop a complete and functional understanding of the language's grammatical structure, enabling them to construct their own sentences with confidence.

## MTM Philosophy

### Teacher Responsibility
The teacher takes 100% responsibility for student learning. Students should never feel pressure to memorize or "try hard." If a student doesn't understand, it's the teacher's fault, not theirs.

### Understanding Over Memorization
All material is presented for understanding, not memorization. Every new piece of information is a logical extension of what the student already knows.

### Stress-Free Environment
- No memorization required
- No homework
- No pressure or tension
- Relaxed, conversational learning

### Ladder of Success
Content builds logically, where every new piece of information is a natural extension of previous learning. Errors are avoided by design.

- {Objective 3}

This curriculum is organized into {N} modules, each focusing on a specific grammatical concept or communication skill. Modules progress from foundational concepts to more complex structures.
```

## Key Guidelines for Templates

1. **Consistency:** Use the same structure across all README files
2. **Clarity:** Write in clear, accessible language
3. **Completeness:** Include all required sections
4. **Accuracy:** Ensure all information is correct and up-to-date
5. **Formatting:** Use proper Markdown syntax with appropriate heading levels
6. **Tables:** Use Markdown tables for structured information
7. **Emphasis:** Use bold for important terms, italics for emphasis
